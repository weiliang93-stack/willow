Export

Downloads every entry as a .zip: a JSON file with all your entries, plus a media/ folder with the actual photos/videos. Since attachments only live in this browser's storage, this is the way to back them up.

Import from Day One

One-time import of a Day One JSON (.zip) export. Photos and videos are extracted into this browser's storage only — they won't appear on other devices unless re-imported there. This is a plain-text diary, so Day One's markdown formatting (**bold**, # headings, etc.) will show up as raw characters. Re-importing the same file skips entries already imported.
